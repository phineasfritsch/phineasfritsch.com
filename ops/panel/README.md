# Panel material

The panel's fact base and briefs are **not in this repository**. They live in
`ops/private/`, which is gitignored, because this repository is public and they
contain personal details — a phone number, a GPA, and a frank assessment of other
repositories — that were never meant to be published.

`ops/private/EVIDENCE.md` remains the rule it always was: **nothing reaches the site
or the resume that is not in it.** Being untracked does not make it optional. Anyone
working on this without a copy should ask for one rather than reconstructing it from
memory, because reconstructing it from memory is precisely how an invented fact gets
onto a resume.

What is public here is the machinery: the gate, the sanity checks, the pinned claims,
and the operating manual. That is the part worth reading anyway.
